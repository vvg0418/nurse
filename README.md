# alina

Сайт-визитка к дню рождения. Статический сайт на Vercel, данные в Supabase.

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | Страница. Тексты с атрибутом `data-text` можно менять из админки |
| `css/site.css` | Все стили, включая мобильную версию |
| `js/config.js` | Какая база используется: боевая на основном адресе, тестовая на превью |
| `js/site.js` | Анимации и сценарий прокрутки (GSAP, Lenis) |
| `js/features.js` | Отзывы, поздравления, лайки, письмо, квиз, мысли, галерея, голоса, пасхалки |
| `admin.html`, `js/admin.js` | Админка: `/admin.html` |
| `card.html` | Открытка А6 с QR-кодом для печати |
| `og.jpg` | Картинка-превью для ссылок в мессенджерах |
| `api/keepalive.js`, `vercel.json` | Ежедневный пинг, чтобы бесплатный Supabase не засыпал |
| `supabase/migrations/` | Схема базы |

## Базы

- Боевая: проект `nurse`, используется на `alishka-eight.vercel.app`.
- Тестовая: проект `nurse-dev`, используется на превью и при локальном просмотре.

## Полезное

- Режим дня рождения можно посмотреть заранее: добавьте `#bday` к адресу.
- Скрыть отзыв: админка → Отзывы → «Скрыть», или в Supabase поставить `hidden = true`.
- Админы перечислены в таблице `admins` (по почте).
